解决什么问题 / 适用场景

浏览器里需要 3D 场景、粒子与交互可视化，2D CSS 不够。

结合本站摘要，典型场景还包括： 落地页放轻量 3D hero（低面数模型 + 简单光照）；或用 React Three Fiber。注意性能与移动端降级。酷站用法：背景网格/球体轻微漂浮，别抢内容焦点。

E

和同类怎么选 / 注意点

同站动效线：Motion/Lenis/Magic UI 覆盖 2D UI；three.js 是 WebGL 事实标准。落地页只需轻量 hero 时控制面数与光照；复杂场景可用 React Three Fiber。勿与满屏 UI 动效叠加重负。

F

快速结论

记住这句

需要真 3D → three.js；2D UI 动效 → Motion/Magic UI；滚动质感 → Lenis。
