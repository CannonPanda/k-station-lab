解决什么问题 / 适用场景

Claude Code 默认前端输出易模板化，需要可落地的 skills/插件/MCP/CLAUDE.md 清单。

结合本站摘要，典型场景还包括： 按仓库清单安装推荐的 frontend-design 相关 skill/插件，并把 CLAUDE.md 约定并入项目；写落地页、组件与改版时引用，最大化前端观感上限。
