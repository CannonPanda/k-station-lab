解决什么问题 / 适用场景

落地页需要光效边框、粒子、文字特效等「一眼很酷」的块，自写成本高。

结合本站摘要，典型场景还包括： 落地页 hero、特性区、CTA 直接抄组件再改色。与 shadcn/Tailwind 同栈。想站点「一眼很酷」时优先用 Marquee、Shine Border、Animated Beam、Blur Fade 等。

E

和同类怎么选 / 注意点

相对 shadcn：Magic UI 是特效层，不是表单/对话框全家桶。相对 Motion：Magic UI 是预制组件；Motion 是通用动画原语。常见组合：shadcn + Magic UI + Motion（少量）。

快速结论

要预制酷站特效 → Magic UI；要自控动画时间线 → Motion；要基础件 → shadcn。
