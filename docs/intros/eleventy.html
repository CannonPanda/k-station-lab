解决什么问题 / 适用场景

框架束缚多时，想完全掌控 HTML/CSS，又要静态输出与分页、图片优化。

结合本站摘要，典型场景还包括： 适合想完全掌控 HTML/CSS、少框架束缚的酷站。用 Nunjucks/Liquid/11ty Image 等插件做图片优化与分页。与 Tailwind 搭配做作品集、杂志风站点很顺手。

怎么用好

适合想完全掌控 HTML/CSS、少框架束缚的酷站。用 Nunjucks/Liquid/11ty Image 等插件做图片优化与分页。与 Tailwind 搭配做作品集、杂志风站点很顺手。

E

和同类怎么选 / 注意点

相对 Astro/VitePress/Hugo：Eleventy 极简，模板引擎可选（Nunjucks/Liquid 等），几乎不 bundler 绑架。代价是文档站/岛屿生态要自己拼。酷站、杂志风、作品集很适合；要开箱文档主题选 VitePress，要岛屿选 Astro。

F

快速结论

记住这句

要掌控干净 HTML → Eleventy；要文档默认体验 → VitePress；要岛屿 → Astro。
