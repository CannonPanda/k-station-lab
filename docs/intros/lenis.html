C

解决什么问题 / 适用场景

默认滚动偏「网页感」，高端作品集需要更丝滑的整页滚动质感。

结合本站摘要，典型场景还包括： 在布局里初始化 Lenis，并与 ScrollTrigger / Motion 的滚动监听同步。适合长落地页与作品集；记得尊重 prefers-reduced-motion。

D

怎么用好

在布局里初始化 Lenis，并与 ScrollTrigger / Motion 的滚动监听同步。适合长落地页与作品集；记得尊重 prefers-reduced-motion。

补充： 在布局里初始化 Lenis，并与 Motion 的滚动监听同步。适合长落地页与作品集。

E

和同类怎么选 / 注意点

相对 Motion：Lenis 管滚动插值；Motion 管元素。长落地页与作品集常两者一起，并与 ScrollTrigger 等同步。务必尊重 prefers-reduced-motion。
