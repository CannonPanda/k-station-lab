用法

pip install markitdown 后用 CLI 或 MarkItDown().convert(path)；把杂格式附件统一成 Markdown 再进 RAG/Agent。轻量批转、插件/管道集成优先它；要复杂版式与公式级 PDF 解析时搭配 MinerU。
