怎么用好

用 npm create astro 起步；交互块用岛屿。配 Tailwind + 静态输出。酷站可开 View Transitions，严格控制客户端岛数量。

记住这句

内容为主、交互为辅 → Astro；纯文档默认体验 → VitePress；极速大站 → Hugo。
