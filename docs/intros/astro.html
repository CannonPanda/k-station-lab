和 Hugo / VitePress / Eleventy 怎么选

维度 Astro VitePress Hugo Eleventy
默认 JS ✓零 JS + 岛 !文档壳有 Vue ✓几乎无运行时 ✓干净 HTML
文档约定 !自搭 ✓开箱文档 UX !主题自制 !自拼
构建速度 ✓快 ✓Vite ✓极致 Go ✓中等
组件岛 ✓多框架 !绑 Vue ✗弱 ✗弱
酷站适配 ✓强 !偏文档 ✓主题/partials ✓杂志风

内容为主、交互为辅 → Astro；纯文档默认体验 → VitePress；极速大站 → Hugo；要完全掌控标记 → Eleventy。

D

落地要点

用 npm create astro 起步；内容用 Markdown/MDX，交互块用 React/Vue/Svelte 岛屿。配 Tailwind + 静态输出，部署到 GitHub Pages / Cloudflare 极快。做酷站时优先用 View Transitions 与客户端岛控制动画。

记住

交互块用岛屿，严格控制客户端岛数量；满屏 SPA 不是甜点区。
