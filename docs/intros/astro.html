解决什么问题 / 适用场景

内容站若默认整页 hydration，首屏 JS 过重。文档站、作品集、营销页往往以内容为主，只需少量交互岛。

结合本站摘要，典型场景还包括： 用 npm create astro 起步；内容用 Markdown/MDX，交互块用 React/Vue/Svelte 岛屿。配 Tailwind + 静态输出，部署到 GitHub Pages / Cloudflare 极快。做酷站时优先用 View Transitions 与客户端岛控制动画。

D

怎么用好

用 npm create astro 起步；内容用 Markdown/MDX，交互块用 React/Vue/Svelte 岛屿。配 Tailwind + 静态输出，部署到 GitHub Pages / Cloudflare 极快。做酷站时优先用 View Transitions 与客户端岛控制动画。

补充： 用 npm create astro 起步；交互块用 React/Vue/Svelte 岛屿。配 Tailwind + 静态输出，部署 GitHub Pages / Cloudflare。酷站可开 View Transitions，并严格控制客户端岛数量。

E

和同类怎么选 / 注意点

同站 SSG：Hugo 极致构建速度与主题生态；VitePress 文档站体验一流（Vite+Vue）；Eleventy 模板自由、输出干净。Astro 默认零 JS + 岛屿架构，Markdown/MDX 友好，适合「酷站」与内容营销。要 Vue 文档默认主题选 VitePress；要海量页极速构建选 Hugo；要完全掌控 HTML 选 Eleventy。
