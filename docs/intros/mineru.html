和 markitdown 怎么分工

维度 MinerU markitdown
擅长 ✓复杂 PDF 版式 / 公式 / OCR ✓多格式轻量统一转 Markdown
重量 !偏重（解析引擎） ✓轻、易嵌管道

复杂版式与公式 → MinerU；杂格式附件快速统一 → markitdown；也可串联：先 MinerU 精解析，管道其余用 markitdown。

D

用法

用 pip 安装后对 PDF、DOCX、PPTX、XLSX 跑解析，输出带标题/表格/公式结构的 Markdown 或 JSON，直接喂给 RAG 或 LLM。扫描件开 OCR；批量入库时把它当统一文档清洗层。复杂版式与公式场景优先于轻量转换器。

记住

把它当「文档清洗层」：输出可直接进 RAG/LLM，不必再手撕版式。
