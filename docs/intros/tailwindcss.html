B

它强在哪、弱在哪

类名即样式，拼 UI 快；设计系统靠 theme / @apply 收口。它不是组件库——表单/对话框要接 shadcn 等。

C

和 shadcn / Magic UI 怎么叠

角色 Tailwind shadcn/ui Magic UI
样式原子 ✓底座 ✗消费它 ✗消费它
无障碍组件 ✗无 ✓Button/Dialog… ✗偏特效
落地页特效 !自写 !基础 ✓预制光效
源码归属 ✓框架 ✓复制进仓 ✓复制进仓
别指望它单独给组件

Tailwind 是样式语言，不是组件库。表单/对话框接 shadcn；「一眼很酷」接 Magic UI。

D

酷站怎么用

与 Astro/Vite/Next 任意组合。做酷站时善用自定义 theme（色板、阴影、动画）、@apply 抽组件类，再叠加 backdrop-blur、gradient、grid/bento 布局。v4 用 CSS-first 配置更轻。
