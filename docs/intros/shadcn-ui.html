用法

用 CLI 按需添加 Button、Dialog、Card 等组件到项目。做 App/仪表盘时极快出成品；做酷站可改变体、接 Framer Motion，再与自有设计系统对齐。

组合

结构用 shadcn，英雄区用 Magic UI，原子用 Tailwind。
