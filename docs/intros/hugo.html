怎么用好

装好 Hugo 后选主题快速出站；内容用 Markdown + shortcodes。管线资源处理与内联关键 CSS 做酷站。

记住这句

大量页面 + 要快 → Hugo；要现代组件岛 → Astro；要 Vue 文档站 → VitePress。
