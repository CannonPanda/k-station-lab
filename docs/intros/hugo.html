速度从哪来

这里要强调的是「Go 单二进制 + 构建期展开」，用 annot 标关键短语比再画一张流水线图更贴切。

为什么海量页仍能秒级
Hugo 用 Go 单二进制无 Node 依赖树 扫内容；shortcodes可复用内容块 与主题 partials 在构建期展开，输出纯静态。
现代组件岛要另想办法；要岛屿请看 Astro
C

什么时候选它，什么时候别选

你要… 更合适
大量页面 + 极致构建速度 ✓Hugo
多框架组件岛 / 营销酷站 ✓Astro
Vue 文档站开箱体验 ✓VitePress
完全自控干净 HTML、杂志风 ✓Eleventy
D

用法

装好 Hugo 后用主题快速出站；内容用 Markdown + shortcodes。需要极致构建速度、大量页面时选 Hugo。酷站做法：选现代主题或自写 partials，配合管线资源处理与内联关键 CSS。
