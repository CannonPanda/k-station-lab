文档怎样变成可浏览站

Markdown 进默认主题（侧栏、搜索、首页 hero）；正文可嵌 Vue 做交互 demo。

通用营销站更偏 Astro；极速大站偏 Hugo。

怎么上手

适合 API/项目文档与知识库。用默认主题快速上线，再通过自定义主题、首页 hero、特性卡片做品牌感。配合 Vue 组件可在文档里嵌交互 demo。
