解决什么问题 / 适用场景

项目/API 文档需要侧栏、搜索、首页 hero 的默认好体验，又不想从零搭主题。

结合本站摘要，典型场景还包括： 适合 API/项目文档与知识库。用默认主题快速上线，再通过自定义主题、首页 hero、特性卡片做品牌感。配合 Vue 组件可在文档里嵌交互 demo。

E

和同类怎么选 / 注意点

相对 Astro：VitePress 文档约定更强，默认主题即文档站；Astro 更通用。相对 Hugo：VitePress 与 Vue 生态一体，可在文档嵌交互 demo。相对 Eleventy：VitePress 开箱文档 UX 更好，定制上限在 Vue 主题层。
