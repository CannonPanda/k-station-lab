解决什么问题 / 适用场景

传统 CSS 难快速拼精致 UI；设计系统与响应式要可维护的 utility 层。

结合本站摘要，典型场景还包括： 与 Astro/Vite/Next 任意组合。做酷站时善用自定义 theme（色板、阴影、动画）、@apply 抽组件类，再叠加 backdrop-blur、gradient、grid/bento 布局。v4 用 CSS-first 配置更轻。

怎么用好

补充： 与 Astro/Vite/Next 任意组合。自定义 theme（色板、阴影、动画），必要时 @apply 抽组件类。善用 backdrop-blur、gradient、grid/bento。v4 可用 CSS-first 配置。

E

和同类怎么选 / 注意点

同站 UI 栈：shadcn/ui 在 Tailwind + Radix 上提供可复制组件；Magic UI 提供动画特效组件。Tailwind 是底层样式语言，几乎是现代酷站标配。先 Tailwind，再按需加 shadcn/Magic UI。

F

快速结论

记住这句

样式底座用 Tailwind；要现成无障碍组件加 shadcn；要一眼很酷的动效加 Magic UI。
