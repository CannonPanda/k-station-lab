解决什么问题 / 适用场景

既要高质量无障碍组件，又不要黑盒 npm 包——源码要进自己的仓库。

结合本站摘要，典型场景还包括： 用 CLI 按需添加 Button、Dialog、Card 等组件到项目。做 App/仪表盘时极快出成品；做酷站可改变体、接 Framer Motion，再与自有设计系统对齐。

D

怎么用好

用 CLI 按需添加 Button、Dialog、Card 等组件到项目。做 App/仪表盘时极快出成品；做酷站可改变体、接 Framer Motion，再与自有设计系统对齐。

补充： CLI 按需添加组件。做 App/仪表盘很快；做酷站可改变体、接 Motion，再对齐自有设计系统。

E

和同类怎么选 / 注意点

相对 Magic UI：shadcn 偏 App/仪表盘基础件（Button、Dialog、Card）；Magic UI 偏落地页光效与特效。二者同栈（Radix/Tailwind），常一起用：结构用 shadcn，英雄区用 Magic UI。底座仍是 Tailwind。
