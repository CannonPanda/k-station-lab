解决什么问题 / 适用场景

页面很多时，Node 系构建可能变慢。博客、文档与大型内容站需要秒级重建。

结合本站摘要，典型场景还包括： 装好 Hugo 后用主题快速出站；内容用 Markdown + shortcodes。需要极致构建速度、大量页面时选 Hugo。酷站做法：选现代主题或自写 partials，配合管线资源处理与内联关键 CSS。

怎么用好

补充： 装好 Hugo 后选主题快速出站；内容用 Markdown + shortcodes。管线资源处理与内联关键 CSS 做酷站。需要极致构建速度、大量页面时优先 Hugo。

E

和同类怎么选 / 注意点

相对 Astro：Hugo（Go）构建通常更快，主题/ shortcodes 成熟，但组件岛与现代前端栈整合不如 Astro 自然。相对 VitePress：Hugo 不绑 Vue，更偏传统内容站。相对 Eleventy：Hugo 开箱主题与速度更强，Eleventy 更灵活选模板引擎。

F

快速结论

tip 记住这句

大量页面 + 要快 → Hugo；要现代组件岛 → Astro；要 Vue 文档站 → VitePress。
